## 0. 한 줄 요약 (발표 멘트)

> 「진범 랜덤·용의자 5명은 **엔진 확장**보다 **시나리오·RAG 코퍼스 변형**이 본체입니다.  
> 지금은 한 사건을 깊게 풀 수 있게 3명·고정 진범으로 완성도를 맞췄고,  
> 중장기로는 **변형 케이스 세트**로 확장하는 방향입니다.」

---

## 1. 왜 지금 고정인가 (한계가 아니라 설계 선택)

| 이유 | 설명 |
| :--- | :--- |
| 데모·골든 루트 | 5분 안에 카드→슬랙→네트워크→지목이 재현되어야 함 |
| RAG 정합성 | Smoking Gun 문장이 **특정 인물**을 가리킴 (예: 이대리 MAC) |
| 페르소나 | `is_culprit` / secrets / 자백 경로가 인물별로 다름 |
| 안티패턴 | `culprit_id` 클라이언트 미노출 · 룰은 코드·YAML 권위 |

코드에서 `culprit_id`만 `random.choice` 하면 **증거가 여전히 이대리를 가리켜** 논리 모순이 난다.

## 2. 확장 A — 진범 랜덤 (중기)

### 목표
세션(또는 날짜)마다 진범이 달라져 **재플레이성**을 올린다. 단, 매 세션의 증거·알리바이는 자기완결이어야 한다.

### 권장 접근: **변형 케이스 세트**
`case_01_a` / `case_01_b` / `case_01_c`처럼 **진범만 다른 완성 시나리오**를 만들고, 세션 시작 시 하나를 로드.

```
세션 시작
  → random.choice([case_01_a, case_01_b, case_01_c])  # 또는 가중치
  → 해당 scenario + personas + (필요 시) RAG 인덱스/오버레이 로드
  → 플레이 (culprit_id는 서버만 보관)
```

| 층 | 작업 |
| :--- | :--- |
| Scenario | `culprit_id` · `win_condition` · 공개 overview(스포일러 없음) |
| Personas | 3명 `is_culprit` / secrets / 자백·멘탈 붕괴 경로 재배치 |
| RAG raw | Smoking Gun·미끼가 **그 진범**을 가리키도록 문장 변형 |
| Tools | 노트북/포렌식 대상 ID를 진범에 맞춤 |
| Eval / 골든 루트 | 변형별 정답 경로 (발표 데모는 대표 1케이스 유지 가능) |
| UI 카피 | 「이대리 지목」하드코딩 제거 → 시나리오 드리븐 |

### 비권장 (단기)
세션 중 `culprit_id`만 스왑하고 raw/인덱스는 그대로 두기 → **모순**.

### 성공 기준 (초안)
- [ ] 변형 ≥2종에서 골든 루트 클리어 가능
- [ ] `culprit_id` API/UI 미노출 유지
- [ ] 변형별 Hit@k / 스모크 통과

## 3. 확장 B — 캐릭터(용의자) 5명 (중장기)

### 목표
용의자·레드헤링을 늘려 **탐색 공간**과 몰입도를 키운다.

### 권장 접근: **새 케이스 (`case_02`)**
기존 `case_01`을 억지로 5명으로 늘리기보다, **새 사건 + 용의자 5**를 통째로 설계.

| 층 | 작업 |
| :--- | :--- |
| Personas | +2명 YAML · 말투 · 알리바이 · secrets |
| Assets | 전신/프로필 이미지 (±오디오) |
| RAG | 출입·메신저·카드·넷에 **새 인물 노이즈·미끼** · 재 ingest/index |
| Scenario | `suspects` 5 · 잔류 인원·인트로 문장 |
| Balance | 타이머 · 3-Out · 심문 턴 · 진범 1 vs 무고 4 |
| UI | 용의자 선택·도ossier 레이아웃(3명 그리드 → 5명) |
| Agent | `suspect_a/b/c` 하드코딩 분기 → 시나리오/페르소나 일반화 |
| Eval | 새 Smoking Gun·골든 루트 |

### 설계 주의
- 인원만 늘리면 난이도↑·재미≠. **미끼 증거 밀도**가 핵심.
- 데모는 여전히 「대표 루트 1개」를 짧게 보여 주는 편이 안전.
- **5명 + 진범 랜덤**은 사실상 변형 케이스 × N → 데이터 비용이 배로 증가.

### 성공 기준 (초안)
- [ ] `case_02` 페르소나 5 · 공개 API에 secrets/culprit 미노출
- [ ] Advanced Hit@k 목표 Smoking Gun 세트 정의·측정
- [ ] UI에서 5명 심문·지목 완주

## 5. Q&A 치트시트

**Q. 진범을 랜덤으로 할 수 있나요?**  
A. 가능합니다. 다만 ID만 바꾸면 안 되고, **진범별 시나리오·증거 코퍼스**를 준비한 뒤 세션에 로드하는 방식이 맞습니다.

**Q. 용의자를 5명으로 늘릴 수 있나요?**  
A. 가능합니다. 엔진 리스트 확장은 상대적으로 쉽고, **페르소나·아트·RAG 미끼·UI·밸런스**가 본체입니다. 신규 `case_02`로 가는 걸 권합니다.

**Q. 왜 지금은 3명·이대리 고정인가요?**  
A. 제한 시간 데모와 RAG 평가(Hit@k)·골든 루트 재현을 위해 **한 사건을 깊게** 만들었습니다. 확장은 로드맵에 명시했습니다.

**Q. LLM만 바꾸면 되나요?**  
A. 아닙니다. 승패·진범은 **코드·YAML 권위**이고, 증거는 **검색 코퍼스**에 있습니다. 모델은 말투·심문 연출 층입니다.
